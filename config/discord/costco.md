# 📦 How Costco works

**Treat it like a treasure hunt.** There's no schedule, and October through December is usually the busiest time.

**You'll need a membership.** The limit is usually 1 or 2 per membership.

**Before you drive over**
1. Set **My Warehouse** on Costco.com.
2. Check whether your warehouse has it.
3. Call the warehouse with the item number.

💡 Costco bundles can cost less than the normal store price, so they're worth checking.
