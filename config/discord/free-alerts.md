# 📡 Free alerts that are faster than this server

This server is great for knowing what's coming, but it isn't instant. These free services alert within seconds. Prices can change, so confirm they're still free.

• **Restockd:** https://restockd.app/blog/pokemon-discord
• **TrackaLacker:** https://www.trackalacker.com/articles/news/best-free-pokemon-restocks-discord-server
• **PikaNotify** (free alerts arrive 5 minutes late): https://pikanotify.com/
• **Pokemon Restocks and Alerts:** https://discord.com/servers/pokemon-restocks-and-alerts-1369077918244012072

# 🔗 Send their alerts into this server

If one of those servers has an announcement channel, open it, press **Follow**, and choose {{other-stores}}. Their alerts will show up here.

How it works: https://support.discord.com/hc/en-us/articles/360028384531-Channel-Following-FAQ
